# Web Research

## When to use
The task asks to explain, look up, compare or verify something that needs current sources.

## Steps
1. Restate the question in one sentence and list 2-4 sub-questions.
2. Run one `web_search` per sub-question. Prefer original sources (official docs, papers, vendor pages) over aggregators.
3. Cross-check key facts in at least two sources; note disagreements.
4. Write the briefing:
   - **Answer** — 2-4 sentences
   - **Findings** — bullets, each with a source link
   - **Uncertainty / gaps** — what is unclear or unverified
